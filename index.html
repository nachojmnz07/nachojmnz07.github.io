Proyectos

1. BiblioJava: gestor de biblioteca por consola

  • Problema: controlar libros, socios y préstamos de una biblioteca pequeña sin hojas de cálculo.
  • Tecnologías: Java, POO (herencia, interfaces, polimorfismo), colecciones, excepciones propias, ficheros, Eclipse, Git.
  • Mi aportación: proyecto individual. Diseñé las clases, el menú por consola, las validaciones y el guardado de datos en fichero.
  • Lo que aprendí: a repartir responsabilidades entre clases y a controlar errores con excepciones.

2. StockSQL: control de inventario con base de datos

  • Problema: llevar el stock de una tienda (productos, categorías, proveedores y movimientos) sin perder los datos al cerrar el programa.
  • Tecnologías: Java, MySQL, SQL (JOIN, GROUP BY, subconsultas), JDBC, patrón DAO, modelo E/R.
  • Mi aportación: diseñé el modelo E/R y las tablas, escribí consultas de informes (stock bajo, ventas por categoría) y programé la capa DAO en Java.
  • Lo que aprendí: a relacionar tablas, separar el acceso a datos del resto del código y conectar Java con una base de datos.

3. TareasAPI: API REST con Spring Boot (prototipo)

  • Problema: gestionar tareas por usuario mediante una API que pueda usar una web o una app móvil.
  • Tecnologías: Java, Spring Boot, Spring Data JPA (Hibernate), H2/MySQL, Maven, Postman.
  • Mi aportación: proyecto individual. Hice las entidades, los repositorios, los controladores CRUD y probé los endpoints en Postman.
  • Lo que aprendí: cómo funciona una API REST y la estructura controlador-servicio-repositorio.
